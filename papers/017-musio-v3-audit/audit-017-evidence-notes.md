## 証跡収集（audit017.py、再実行可能）
- 母集団: ~/workspace/musio-bgm/bulk-v3/ の zip 50件、同フォルダ manifest.json、~/workspace/musio-bgm/queue.json（50件）。
- 方法: zip を開いて内容物一覧・CRC（testzip）・各メンバーのバイト数を取得。track.mid の SHA-256 を manifest の song_mid_sha256 と照合。track.json の title/genre/bpm/key を manifest と queue の双方と照合。track.mp3 は ffprobe で尺・コーデック・サンプルレート・ビットレートを取得し、ffmpeg volumedetect で max/mean volume を全曲測定。track.mid は独自SMFパーサで解析（ノートオン数・チャンネル・音高域・テンポ・尺換算・ドラムチャンネル（ch10）のキック（音高35/36）配置から小節単位の四つ打ち判定）。cover.jpg は PIL で形式・寸法を確認。
- 四つ打ちの定義: 4/4前提（MIDI内に拍子イベントなし。作曲側の設計が4拍子前提）で、1小節内にキックが16分ステップ0・4・8・12の全てに（量子化許容±1/4ステップで）存在する小節。分母はドラム音が存在する小節。
- 結果ファイル: audit-017-results.json（全50曲の個別記録＋集計）。集計の要点は論文第4章に記載。全主要数値は同ファイルに追跡可能。
